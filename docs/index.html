    About

    A fan-made viewer for the armour of Monster Hunter 4 Ultimate, with the game's own models, textures and names. Not affiliated with, endorsed by, or supported by Capcom.

    Game content

    Monster Hunter 4 Ultimate and all of its models, textures, animations and data tables are © CAPCOM CO., LTD. All rights reserved. Every asset here was extracted from a personally owned copy of the game and is shown for reference only.

    What you are looking at

    Each armour piece is its own model in the game, worn over the hunter's skeleton. The names, which model a piece draws for each gender, the clothing shown under an empty slot, each piece's own pigment, and which parts of the hair and face a helm leaves visible all come from the game's own tables.

    Tools used to build this

    • RevilLib / RevilToolset — by PredatorCZ (Lukas Cone) Converted MT Framework .mod meshes to glTF, .tex textures to DDS and .lmt motion lists to animation.
    • three.js Renders the scene, with GLTFLoader, OrbitControls and SkeletonUtils.
    • Pillow Converted the extracted textures during the build.

    Assets

    The theme icons are the game's own monster icons. The UI textures and the MHFU font are shared with the same author's MHGU fan apps. Armour names come from the game's own text files.
